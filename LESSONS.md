# Lessons

- A negative public lookup isn't claimability. Use NO_RECORD_FOUND; hidden holders and ambiguous responses stay unresolved. Test both before changing a parser.
- Parse RDAP JSON and require a matching domain object or a structured registry no-record response. Never search raw bytes for an error number.
- WHOIS help/disclaimer prose must not override a matching registration. Use query-specific anchored negatives; unknown formats stay unresolved.
- Synthetic pronunciation differences are review signals, not automatic cross-language vetoes. Keep human testing separate.
- One creative score convention, /80, is shared by instructions, references and template. Verification evidence never becomes a guessed legal score.
- Canonical instructions must regenerate deterministic agent adapters; CI checks drift before release.
- Verify current official Action releases before adding CI; older remembered majors can introduce deprecated runtime warnings even when tests pass.
- A narrow clone may not create a remote-tracking ref after pushing a new branch. Fetch that explicit ref before comparing remote HEAD with local HEAD.
- Before accepting character artwork, trace each visible hand through one forearm and upper arm to its shoulder. A thinking pose plus two tool-holding hands can accidentally create a third arm; count limbs before embedding the asset.
