# Creative comparison

Score eight dimensions 0–10, maximum **80**. These are comparative judgments, not measured success probabilities. Use the same brief, anchors and competitor sample for every candidate.

| Dimension | Question |
|---|---|
| Positioning | Does it support the name's specific job? |
| Distinctiveness | Does it stand apart from relevant competitors? |
| Depth | Does it support useful associations without a contrived story? |
| Energy | Does its tone fit how the product should feel? |
| Humanity | Does it suit the intended human relationship and level of warmth? |
| Sound | Can target users comfortably say and recognise it? |
| Appearance | Does it work as a word in the same neutral context? |
| Curiosity | Does it invite attention relevant to the brief? |

Use 0–3 for poor fit, 4–6 for mixed fit, 7–8 for strong fit and 9–10 only with a clear reason. Give one concise reason per score. If using weights, set them before seeing candidates, sum to 100%, and report the weighted total /100 separately from the raw /80.

Keep domain/handle observations, acquisition costs, linguistic risks and preliminary trademark research in a separate evidence matrix. Unknown is unknown, not 5/10. A true hard requirement can veto a high creative score; a total cannot erase a conflict.

Carry roughly 8–15 into investigation when useful and present 3–5. Actual counts can differ; explain why. If asked, recommend a best fit with compromises and unresolved checks. The user chooses.

## Read the pattern

High positioning with low distinctiveness suggests a crowded execution of a useful idea: change mechanic within the same territory. Strong scores with poor human spelling-back suggest a real acquisition cost that the creative total mustn't hide. A whole shortlist with weak curiosity can mean the generation was too safe; explore another territory instead of inflating scores.

Score a few relevant competitor names with the same criteria for scale. Show neutral context sheets before totals when possible. Keep name order shuffled for human feedback, record why a candidate fits, and avoid dressing one finalist in a better visual identity than the others.
