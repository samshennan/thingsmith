# The brief

Write the name's job in one sentence. Ask only what isn't known and changes the work.

Record what is being named, its audience and category, the differentiator it should convey, and how people first encounter it: spoken, written, searched or in a package registry. Record brand-family rules and examples the user likes or dislikes, with reasons.

State target markets and languages in priority order. Include local script and any transliteration needs; don't presume a market pair. Separate display name from domain/handle spelling. Check local registration eligibility with the relevant provider rather than assuming every local TLD is open.

Record exact-match domain requirements, acceptable alternatives, critical handles, acquisition/renewal budget and decision maker. Mark unknowns and assumptions. The name need not carry the whole product description; a descriptor can explain it.

Compact scope targets 40–60 distinct ideas; full scope targets 150+. Choose effort with the user or state a reasonable default. Record actual work, not merely targets.
