# Generation

Build a bounded vocabulary from the brief, territories, practitioner language and adjacent fields. Use dictionaries or other credible sources for claimed meanings and etymologies. Never fabricate a foreign derivation to justify a pleasing syllable.

For full scope use four isolated generators if supported:

| Team | Receives |
|---|---|
| Straight | Real brief and competitor map |
| Displaced | Same naming job disguised as another category |
| Unexpected | Only the unusual territories and essential constraints |
| Cold | One sentence describing the thing and audience |

Merge only after generation. Record actual model/context isolation. When unavailable, disclose sequential single-context passes; don't call them isolated teams. The host's permissions and concurrency limit still apply.

Compact scope targets 40–60 distinct candidates; full scope 150+. Vary real-word lifts, compounds, archaic words, portmanteaux, truncations, morpheme assembly and sound-led coinages. A minor spelling change is a variant, not a fresh idea. Track root families so one root doesn't dominate the pool.

Record candidate ID, spelling, territory, type, mechanic, source root and actual generator. Label invented associations as invented. Treat length, syllables and ASCII as brief-dependent preferences, not universal international rules. A pronounceable display name may need a separate domain spelling.

If too few survive, change territories or mechanics. Never weaken an essential constraint or serious risk screen to meet a target. Report actual counts and shortfalls.

## Mechanics to vary

| Mechanic | Move | Check afterwards |
|---|---|---|
| Arbitrary lift | Use a familiar word from a distant field | Category associations and collisions |
| Foreign lift | Borrow a meaningful word from a named language | Actual meaning, local usage and appropriateness |
| Archaic revival | Recover a less-used word | Can users say it without a history lesson? |
| Compound | Join two everyday words | Concatenated URL and distinctiveness |
| Verb | Use an action the product makes possible | Fit beyond the first feature |
| Suffix | Add a short ending to a genuine root | Whether the pool becomes interchangeable |
| Truncation | Keep a recognisable, sayable core | Lost meaning or ambiguous spelling |
| Consonant change | Adjust a root to ease target-market reading | New meanings and spelling cost |
| Portmanteau | Fuse two roots that remain audible | Whether either root needs explanation |
| Vowel change | Explore a root's sound variants | Local readings and root-family duplicates |
| Morpheme assembly | Combine meaningful parts | Verify the derivation; don't promise legal availability |
| Prefix | Put a useful frame on a short stem | Familiarity versus crowded category habits |
| Deliberate respelling | Make a familiar word look different | Human spelling-back cost |
| Sound-led | Start with rhythm, then seek an honest association | Avoid inventing a false etymology |

Use a small prefix/root or root/ending matrix if free association stalls. Keep candidate rows by mechanic as well as territory so a pool of near-identical coinages is visible. Don't exhaust every possible combination for its own sake.

Finish with a brief unusual pass: the founder's observation, a ritual the product changes, a failure it prevents, or the plausible sibling of an intentionally excessive name. Judge against the real brief at the merge. Record which generator contributed useful finalists, not just which produced most words.
