# Competitor map

Use a bounded relevant sample: direct competitors and a few adjacent alternatives in the stated markets. Record sources and access date; do not claim every competitor was found. Separate similarly named unrelated businesses from category conflicts.

Map names by approach (descriptive, experiential, evocative, invented) and construction (real word, compound, coined, acronym or other). Note tone, common roots and repeated suffixes. Search-engine prominence and name similarity are different observations.

Identify crowded patterns and possible alternatives. An empty cell is a creative hypothesis, not proof customers want it. Compare candidate names against the same competitor set later.

Output a compact table: name, source, market/category, approach, construction, notable association. Finish with one crowded pattern and one promising direction to explore.
