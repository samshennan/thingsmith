# Native-speaker feedback

Fill in the shortlist and use independent respondents familiar with the target market. Start with several per priority language; record sample size and regional coverage. This is directional feedback, not statistical validation. Ask permission before recording anyone and avoid storing unnecessary personal details.

## Part A: spoken, with names hidden

Hi — I'm testing possible names. I'll say each once. Please write what you'd type to find it. There are no right answers; uncertainty is useful. Do this before seeing the written names.

## Part B: written, before explaining the product

Show the names in a different order for each respondent. Ask how they'd say each, what it reminds them of, and whether it has an existing meaning, slang or an awkward association. Record their words. Don't explain the intended derivation first.

## Part C: with product context

Explain the product in one plain sentence. Which names could do the intended job, and why? Which would be hard to remember or find after hearing? Ask for the reason rather than only a favourite. An optional later recall task should record the delay and conditions.

## Interpret carefully

A credible serious bad-meaning report pauses the candidate for corroboration. Ordinary accents or different local readings aren't automatic failures. Small-sample spelling errors indicate something to investigate; never report a universal failure rate from a few people. Keep observations separate from your decision. Log unresolved questions and human tests that haven't happened.
