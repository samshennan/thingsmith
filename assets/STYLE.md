# Thingsmith illustration style

Voice: homely, curious and welcoming. A little workshop where anyone can make something. Light editorial ink drawing, imperfect charcoal lines, rounded forms and subtle paper grain. Avoid heavy factory imagery or aggressive tool symbolism.

| Token | Colour | Use |
|---|---|---|
| Paper | #F6F0E5 | Main background and breathing room |
| Ink | #27332F | Type, outlines and strongest contrast |
| Coral | #DC6247 | Anvil and small focal accents |
| Sage | #91A88E | Aprons, plants and secondary objects |
| Honey | Warm wood tones | Letterpress blocks and workbench |

Keep the same friendly dark-haired maker in a sage apron where a person helps. Show others for listening and language feedback. Let poses tell the story. A few clear objects work better than a crowded diagram. No flag shortcuts for languages or claims of guaranteed availability.

Tagline: **A little forge for naming your next big thing.**

Use wide illustrations in the README. Marketing thumbnails use larger lettering and a single idea with generous safe margins. Type should remain readable at 320px wide. Keep semantic content in Markdown and alt text; illustrations aren't the only explanation.

Assets were generated with OpenAI's image-generation tool for this project following the visual direction Sam chose. The neutral candidate context sheet deliberately has no workshop branding, so visuals don't pick a winner.
